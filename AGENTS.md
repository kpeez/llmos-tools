# Agent instructions

This repository owns the `llmos-vault` Python package and the `llmos` agent
plugin. The package, hooks, skills, manifests, marketplace catalogs, and tests
must stay usable from this repository root.

Preserve unrelated working-tree changes. Do not commit, push, or publish
without explicit authorization. Keep the real llmOS vault outside this
repository and use `LLMOS_ROOT` or the documented resolver when testing it.

Before declaring a change complete, run the relevant `just` recipes. The full
local gate is `just check`; package artifacts are checked with `uv build`.
Marketplace catalogs are generated by `scripts/gen-marketplaces.py` and must
remain in sync with the plugin manifest.
